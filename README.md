# SDC-JS

**SDC-JS** is the JavaScript library for working with the **Satia Document Container (SDC)** format —  
a container file format that can hold different kinds of text documents such as JSON, XML, Markdown, and AsciiDoc without escape.

## Specification
This implementation follows the [Tohjiwa SDC Specification](https://sdc.research.tohjiwa.com).
